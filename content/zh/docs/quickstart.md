# 快速开始

本文档帮助您在安装完成后，快速完成账号注册、登录和首次连接。

## 注册账号

ReSocks 支持**匿名使用**，无需提供任何个人信息：

- 直接点击"连接"即可免费试用
- 如需购买订阅，只需提供邮箱地址

## 登录账号

1. 打开 ReSocks 应用
2. 点击右上角的 **用户图标**
3. 输入您的邮箱和密码
4. 点击 **登录**

## 选择节点

登录后，您可以选择合适的服务器节点：

| 节点类型 | 说明 | 适用场景 |
|---------|------|---------|
| BGP 高速节点 | 多国骨干网络直连 | 日常使用、流媒体 |
| 动态住宅 IP | 180+ 国家真实 IP | 解锁地区限制 |
| 静态住宅 IP | 固定真实 IP | 业务需求 |
| 纯 IPv6 节点 | IPv6 专用 | IPv6 环境 |

## 连接

1. 选择目标节点（或使用推荐节点）
2. 点击 **连接** 按钮
3. 首次连接需要授权（见安装指南）
4. 连接图标变绿 ✅ 表示连接成功

## 验证连接

连接成功后，您可以访问以下网站验证：

- [Google](https://www.google.com)
- [YouTube](https://www.youtube.com)

## 断开连接

点击主界面的 **断开** 按钮即可断开连接，也可以直接退出应用程序。
