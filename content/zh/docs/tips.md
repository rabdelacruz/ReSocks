# 使用技巧

本文汇总了一些能让 ReSocks 发挥最佳性能的实用技巧。

## 选择最佳节点

### 延迟测试

在节点列表中点击 **测速** 按钮，ReSocks 会自动测试各节点延迟，选择延迟最低的节点。

### 节点选择建议

| 用途 | 推荐节点类型 |
|------|-------------|
| 日常浏览 | BGP 高速节点（就近选择） |
| 流媒体（Netflix/YouTube） | 流媒体专用节点 |
| 访问 AI 服务 | 美国 / 欧洲节点 |
| 住宅 IP 需求 | 动态住宅 IP 节点 |

## 提升连接速度

### 1. 使用 TUN 模式

TUN 模式在系统层工作，避免了部分系统代理的额外延迟。

### 2. 关闭不必要的后台应用

减少与代理竞争带宽的应用程序，有助于提升速度。

### 3. 启用快速切换

在设置中开启 **快速节点切换**，可以在不断开连接的情况下更换节点。

## 后台运行

ReSocks 支持控制界面和核心程序分离：

- 关闭控制界面窗口后，**核心程序仍在后台运行**
- 代理连接不会中断
- 可通过系统托盘图标重新打开控制界面

## 多设备使用

同一账号支持 **8 台设备** 同时在线，登录方式：

1. 在新设备上安装 ReSocks
2. 使用相同的邮箱和密码登录
3. 即可在所有设备间共享订阅

## IPv6 加速

如果您的网络支持 IPv6：

1. 在设置中开启 **IPv6 支持**
2. 选择 **纯 IPv6 节点**
3. 在部分地区和运营商下，IPv6 节点延迟更低

## 代理分享给其他设备

将代理共享给电视、游戏机等不支持安装应用的设备：

```
代理类型：HTTP
代理地址：您电脑的局域网 IP（如 192.168.1.100）
代理端口：默认2022，在 ReSocks 网络设置中查看
```
