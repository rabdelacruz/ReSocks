# 如何使用住宅IP

住宅IP是真实家庭宽带分配的IP地址，相比数据中心IP更加可信，适合需要高匿名性和稳定性的场景。

## 什么是住宅IP？

住宅IP具有以下特点：

- ✅ **真实性高**：来自真实的家庭网络环境
- ✅ **信任度高**：不易被网站识别为代理
- ✅ **覆盖广泛**：支持 180+ 国家和地区
- ✅ **IP 池庞大**：数千万级别的 IP 可供使用

## 适用场景

住宅IP特别适合以下使用场景：

| 场景 | 说明 |
|------|------|
| **社交媒体** | Instagram、Facebook、Twitter 等平台账号管理 |
| **电商平台** | Amazon、eBay 等跨境电商业务 |
| **广告验证** | 广告投放效果验证和监测 |
| **数据采集** | 网页爬虫、市场调研数据收集 |
| **流媒体** | Netflix、Hulu 等地区限定内容访问 |
| **AI 服务** | ChatGPT、Claude 等对 IP 质量有要求的服务 |

## 添加住宅IP服务器

### 步骤 1：进入住宅IP管理

1. 打开 ReSocks 应用
2. 进入 **控制面板 → 服务器选择**
3. 切换到 **住宅IP服务器** 标签页

### 步骤 2：添加动态住宅IP

1. 点击 **添加动态住宅IP** 按钮
2. 在弹出的对话框中进行配置：

**配置选项**：

| 选项 | 说明 | 示例 |
|------|------|------|
| **代理池** | 选择一个可用的代理池 | 默认代理池 |
| **国家** | 选择目标国家（必选） | 美国、英国、日本等 |
| **城市** | 选择具体城市（可选） | 纽约、伦敦、东京等 |
| **生成数量** | 需要生成的IP数量 | 1-1000 个 |

3. 配置完成后，点击 **保存**

::alert{type="info"}
**提示**：生成数量建议根据实际需求选择，每个IP都会占用一定的资源配额。
::

### 步骤 3：选择并连接

1. 返回 **服务器列表**
2. 找到刚才添加的住宅IP服务器
3. 点击选择该服务器
4. 返回 **控制面板**
5. 点击 **连接** 按钮

连接成功后，您的网络流量将通过选定的住宅IP进行访问。

## 使用技巧

### 1. 选择合适的国家

根据您的目标服务选择对应的国家：

- **访问美国服务**：选择美国住宅IP
- **访问日本内容**：选择日本住宅IP
- **跨境电商**：选择目标市场所在国家

### 2. 城市选择（可选）

如果需要更精确的地理位置：

- **流媒体**：某些服务对城市有限制
- **广告验证**：特定城市的广告投放验证
- **本地化测试**：测试不同城市的用户体验

### 3. IP 数量管理

合理控制生成的IP数量：

- **单账号使用**：1-2 个IP即可
- **多账号管理**：根据账号数量生成对应IP
- **批量任务**：可生成多个IP轮换使用

### 4. 定期更换IP

对于长期使用的场景：

1. 定期删除旧的住宅IP
2. 重新生成新的住宅IP
3. 保持IP的新鲜度和活跃度

## 常见问题

### Q: 住宅IP和普通服务器有什么区别？

**A**: 
- **住宅IP**：来自真实家庭网络，信任度高，不易被识别为代理
- **数据中心IP**：来自服务器机房，速度快但容易被识别

### Q: 住宅IP的速度如何？

**A**: 住宅IP的速度通常略低于数据中心IP，但对于大多数应用场景（如浏览网页、使用AI服务）完全够用。

### Q: 可以同时使用多个住宅IP吗？

**A**: 可以。您可以添加多个住宅IP服务器，并根据需要切换使用。

### Q: 住宅IP会过期吗？

**A**: 动态住宅IP有一定的有效期，会自动重新生成新的。

### Q: 如何知道当前使用的是住宅IP？

**A**: 连接成功后，可使用浏览器到相关网站查询。

### Q: 住宅IP支持哪些代理模式？

**A**: 住宅IP支持所有代理模式（TUN、系统代理、混合模式），使用方式与普通服务器完全相同。
