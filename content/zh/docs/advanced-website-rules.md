# 智能代理网站规则高级应用

本文介绍如何通过配置网站规则，实现精细化的网络访问控制，让不同网站按需走代理或直连。

## 使用前提

在开始配置之前，请确保已完成以下设置：

1. **规则模式**：切换为 **智能模式**
2. **代理模式**：**任意模式**（TUN 或系统代理均可）

## 工作原理

当应用程序通过 HTTP/HTTPS 访问网站时，如果该应用**没有加入 APP 规则列表**，则该应用访问网站的行为将由**网站规则**决定：

- ✅ **部分网站走代理**：匹配代理规则的网站通过代理访问
- ✅ **部分网站本地直连**：匹配直连规则的网站直接访问
- ✅ **智能判断**：根据网站规则自动选择最佳访问方式

::alert{type="info"}
**注意**：如果应用已加入 APP 规则列表，则 APP 规则优先级更高，网站规则将被忽略。
::

## 高级规则选项

除了默认规则，ReSocks 还提供了多种高级规则选项，让您更灵活地控制网络访问。

### 1. IP 位置代理

根据网站的 IP 地理位置自动判断是否代理。

**可选配置**：
- ✅ **代理所有美国网站**：自动代理所有位于美国的网站
- ✅ **代理所有英国网站**：自动代理所有位于英国的网站
- ✅ **代理所有日本网站**：自动代理所有位于日本的网站

**配置方法**：
1. 进入 **规则编辑 → 网站规则 → 高级选项**
2. 勾选需要的地理位置代理选项
3. 保存设置

**应用场景**：
- 访问美国的流媒体服务（Netflix、Hulu 等）
- 访问日本的动漫网站
- 访问欧洲的新闻媒体

### 2. 广告屏蔽

自动拦截广告和追踪域名，提升浏览体验。

**配置方法**：
1. 进入 **规则编辑 → 网站规则 → 高级选项**
2. 勾选 **屏蔽广告**
3. 保存设置

**效果**：
- ✅ 拦截常见广告域名
- ✅ 阻止追踪脚本
- ✅ 加快网页加载速度
- ✅ 节省流量

### 3. 中国网站直连

确保所有中国大陆网站直接访问，不走代理。

**配置方法**：
1. 进入 **规则编辑 → 网站规则 → 高级选项**
2. 勾选 **中国网站直连**
3. 保存设置

**效果**：
- ✅ 百度、淘宝、微博等国内网站自动直连
- ✅ 访问速度更快
- ✅ 避免因代理导致的访问异常

::alert{type="warning"}
**建议**：强烈建议开启此选项，可以显著提升国内网站的访问速度。
::

## 自定义规则

当遇到默认规则未覆盖的网站，或需要特殊配置时，可以添加自定义规则。

### 规则语法

ReSocks 支持以下规则格式：

```
DOMAIN-SUFFIX,域名,动作
```

**动作类型**：
- `PROXY`：通过代理访问
- `DIRECT`：直接访问（不走代理）
- `REJECT`：拒绝访问（屏蔽）

### 常用规则示例

#### 1. 代理特定网站

```
DOMAIN-SUFFIX,example.com,PROXY
DOMAIN-SUFFIX,mysite.net,PROXY
```

**说明**：将 `example.com` 和 `mysite.net` 及其所有子域名设置为代理访问。

#### 2. 直连特定网站

```
DOMAIN-SUFFIX,localsite.cn,DIRECT
DOMAIN-SUFFIX,company.com,DIRECT
```

**说明**：将 `localsite.cn` 和 `company.com` 设置为直接访问，不走代理。

#### 3. 屏蔽特定网站

```
DOMAIN-SUFFIX,ads.example.com,REJECT
DOMAIN-SUFFIX,tracker.net,REJECT
```

**说明**：拦截广告域名和追踪域名，阻止访问。

#### 4. 精确匹配域名

```
DOMAIN,www.example.com,PROXY
```

**说明**：只代理 `www.example.com`，不包括子域名。

#### 5. 自定义地理位置规则

```
GEOIP,GB,PROXY
GEOIP,US,PROXY
GEOIP,JP,DIRECT
```

**说明**：
- `GEOIP,GB,PROXY`：代理所有英国（GB）的网站
- `GEOIP,US,PROXY`：代理所有美国（US）的网站
- `GEOIP,JP,DIRECT`：直连所有日本（JP）的网站

**常用国家代码**：
- `US` - 美国
- `GB` - 英国
- `JP` - 日本
- `KR` - 韩国
- `SG` - 新加坡

### 添加自定义规则

1. 进入 **规则编辑 → 网站规则 → 规则列表**
2. 选择一个现有规则集，或点击 **新建规则集**
3. 在右边的规则列表中直接编辑规则
4. 或在右下角使用 **规则生成器** 生成规则
5. 保存设置

**示例规则**：
```
DOMAIN-SUFFIX,example.com,PROXY
GEOIP,GB,PROXY
DOMAIN,www.test.com,DIRECT
```


### 规则优先级

当多条规则匹配同一个域名时，按以下优先级执行：

1. **精确匹配** (`DOMAIN`) > **后缀匹配** (`DOMAIN-SUFFIX`)
2. **自定义规则** > **默认规则**
3. **REJECT** > **PROXY** > **DIRECT**

## 实用场景

### 场景 1：访问特定国家的流媒体

**需求**：访问美国 Netflix、日本 Niconico 等地区限定内容。

**配置**：
1. 开启 **代理所有美国网站**（访问 Netflix）
2. 开启 **代理所有日本网站**（访问 Niconico）
3. 或手动添加规则：
   ```
   DOMAIN-SUFFIX,netflix.com,PROXY
   DOMAIN-SUFFIX,nicovideo.jp,PROXY
   ```

### 场景 2：屏蔽广告和追踪

**需求**：提升浏览体验，减少广告干扰。

**配置**：
1. 开启 **屏蔽广告** 选项
2. 添加自定义屏蔽规则：
   ```
   DOMAIN-SUFFIX,doubleclick.net,REJECT
   DOMAIN-SUFFIX,googleadservices.com,REJECT
   DOMAIN-SUFFIX,googlesyndication.com,REJECT
   ```

## 高级技巧

### 组合使用 APP 规则和网站规则

- **APP 规则**：控制整个应用的网络行为
- **网站规则**：控制特定域名的访问方式
- **优先级**：APP 规则 > 网站规则

**示例**：
- Chrome 在 APP 代理列表中
- `baidu.com` 在网站直连列表中
- **结果**：在 Chrome 中访问百度仍然会走代理（APP 规则优先）

## 常见问题

### Q: 为什么配置了网站规则后没有生效？

**A**: 请检查以下几点：
1. 确认规则模式为 **智能模式**
2. 确认该应用**没有**在 APP 规则列表中（APP 规则优先级更高）
3. 检查规则语法是否正确
4. 重启应用或刷新网页

### Q: 如何查看当前生效的规则？

**A**: 进入 **规则编辑 → 网站规则 → 当前规则**，可以查看所有生效的规则列表。

### Q: 网站规则和 APP 规则有什么区别？

**A**: 
- **APP 规则**：控制整个应用程序的所有网络请求
- **网站规则**：只控制特定域名的访问方式
- **优先级**：APP 规则 > 网站规则
