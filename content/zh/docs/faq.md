## � 使用中的故障排查和解决

### 连接后弹出当前服务器可能不能用的提示

**解决方法**：
1. 可能只是这一次测试失败了，请进一步确认是否真的无法访问
2. 例如，打开浏览器，访问网站测试，如果有问题，则继续下面的步骤

### 连接后无法访问任何网站

**问题表现**：连接成功后，在浏览器中无法打开任何网站（包括 google.com、ip138.com、baidu.com 等）

#### 规则模式进行切换后无论智能代理还是全局模式下均无法访问

**步骤 1：修改网络设置**

1. 打开《AI网络加速器》
2. 切换到**网络设置**页面
3. 点左下角**恢复默认**按钮
4. 点击**保存**
5. **重新连接**

**步骤 2：检查服务器状态**

可能是服务器故障，请尝试：

1. **切换节点**：
   - 选择其他节点，如**台湾**或**美国**节点（通常最稳定）
   - 重新连接并测试

2. **更换服务器网关**：
   - 打开《AI网络加速器》
   - 切换到**网络设置**页面
   - 更换**服务器网关**
   - 点击后面的**测试**按钮，查看是否通过
   - 必要时启用上面的**前置解析**选项
   - 保存并重新连接

**步骤 3：检查浏览器设置**

1. **检查浏览器插件**：
   - 关闭广告拦截插件（如 AdBlock、uBlock Origin）
   - 关闭其他代理插件
   
2. **检查浏览器代理设置**：
   - 确保浏览器未单独设置代理

3. **更换浏览器测试**：
   - 尝试使用其他浏览器（Chrome、Firefox、Edge 等）
   - 排除浏览器本身的问题

**步骤 4：检查系统设置**

1. **检查防火墙**：
   - 确认防火墙未拦截网络访问
   - Windows：检查 Windows Defender 防火墙
   - macOS：检查系统偏好设置 > 安全性与隐私 > 防火墙

2. **检查其他 VPN/代理软件**：
   - 确保没有其他 VPN/代理类软件正在运行
   - 如有，请完全退出这些软件

3. **Windows 系统特别注意**：
   - 需要放行安装目录下的 `plugins/redstarn.exe` 的网络访问
   - 在防火墙设置中添加该程序为允许列表

### 智能模式下部分网站无法访问

**问题表现**：在智能规则模式下，只有部分或特定网站无法访问，其他网站正常

#### 解决方法

**方法 1：添加网站代理规则**

1. 打开《AI网络加速器》
2. 切换到**规则编辑**页面
3. 在**网站规则**列表中
4. **添加该网站的代理规则**
5. 保存并重新连接

**方法 2：切换到全局模式**

- 直接将 APP 切换到**全局模式**
- 所有网站都会经过代理访问

**方法 3：添加浏览器到 APP 代理列表**（推荐）

如果您想让某个浏览器的所有网站都经过代理，可以在智能模式下将该浏览器加入 APP 代理列表：

1. 打开《AI网络加速器》
2. 切换到**规则编辑**页面
3. 切换到 **APP 规则列表**
4. 将该浏览器**加入代理列表**
5. **重启服务**

这样该浏览器访问的所有网站都会自动走代理，而系统其他应用仍然按智能规则运行。

### 如何检测当前连接和代理服务是否有效

**问题表现**：不确定代理服务是否正常工作，需要验证连接状态

#### 检测方法

**方法 1：使用 IP 查询功能**

1. 打开《AI网络加速器》
2. 切换到**诊断功能**页面
3. 点击 **运行状态**功能
4. 查看连接状态下，**代理 IP 是否正常显示**
5. 如果显示的是代理服务器的 IP，说明代理服务正常工作

**方法 2：通过浏览器访问 IP 查询网站**

1. 在浏览器中打开 IP 查询网站，例如：
   - [ipip.net](https://ipip.net)
   - [ip138.com](https://ip138.com)
2. 查看显示的 IP 地址是否为**代理 IP**
3. **注意**：有些网站可能没有加入代理列表，显示的可能是本地 IP

**方法 3：运行故障诊断**

如果发现异常，可以运行诊断工具：

1. 打开《AI网络加速器》
2. 进入**诊断功能**页面
3. 运行**故障诊断**功能
4. 查看诊断结果中的**问题项**
5. 根据提示进行相应的修复操作

#### 正常状态判断

- ✅ **代理正常**：IP 查询显示的是代理服务器所在地的 IP
- ❌ **代理异常**：IP 查询显示的仍是本地真实 IP
- ⚠️ **部分代理**：某些网站显示代理 IP，某些显示本地 IP（可能是智能模式下的正常现象）

### 访问网站时出现 502 错误

**问题表现**：访问某个网站时，浏览器显示 502 错误，网站无法访问

#### 解决方法

**情况 1：APP 运行于智能模式**

可能是该网站没有加入代理规则，请尝试以下方法：

**方法 1：添加网站代理规则**

1. 打开《AI网络加速器》
2. 切换到**规则编辑**页面
3. 在**网站规则**列表中
4. **添加该网站的代理规则**
5. 保存并重新连接
6. 刷新浏览器重试

**方法 2：切换到全局模式**

1. 将 APP 切换到**全局模式**
2. 刷新浏览器重试
3. 如果问题解决，说明是规则问题
4. 可以按方法 1 添加规则后，再切换回智能模式

**情况 2：APP 运行于全局模式**

如果已经是全局模式仍出现 502 错误，可能的原因：

1. **网站本身不可访问**：
   - 网站可能暂时维护或关闭
   - 稍后重试

2. **服务器节点故障**：
   - 切换到其他节点（如**台湾**或**美国**节点）
   - 重新连接后重试

#### 快速诊断步骤

1. **确认代理模式**：检查当前是智能模式还是全局模式
2. **测试其他网站**：访问其他网站是否正常，判断是个别网站问题还是全局问题
3. **切换节点测试**：更换不同地区的服务器节点
4. **断开代理测试**：暂时断开代理，直接访问该网站，确认网站本身是否可用

## 💡 使用中的相关问题和技巧

### 为什么网速时而很快，时而很慢，为什么会波动？

**这是国际网络的正常现象，我们的服务器性能稳定，速度波动主要来自您本地到国际出口的网络拥堵。**

#### 为什么会这样？

想象高速公路：晚上 8-11 点是上网高峰期，就像下班高峰期的高速公路一样拥堵。问题不在目的地（我们的服务器），而在路上（国际出口）。

#### 如何获得更好的速度？

- ⏰ **避开高峰**：非高峰时段速度更快更稳定
- 🔄 **换个节点**：不同节点走不同线路，试试其他节点
- 🎯 **选近的节点**：香港、台湾等节点距离近，通常更快

---

### 为什么使用相同的节点，我和别人看到的代理 IP 不一样？

**这是正常的，我们采用智能分配机制。**

#### 节点架构说明

- 🖥️ **服务器集群**：每一个节点由**几十甚至上百台**独立服务器组成
- 🎲 **智能分配**：APP 会智能分配给每一位用户不同的服务器组
- 🔒 **稳定分配**：初次分配完成后一般会稳定使用，不会再变换
- 🛡️ **安全保障**：这样可以保证您使用代理的安全性和稳定性

#### 优势

- 负载均衡，避免单台服务器过载
- 提高可用性和稳定性
- 增强用户隐私保护

### 如何在终端 APP 中使用代理服务？

**有两种方法可以让终端应用使用代理。**

#### 方法 1：加入 APP 代理列表规则（推荐）

1. 打开《AI网络加速器》
2. 切换到**规则编辑**页面
3. 切换到 **APP 规则列表**
4. 将终端应用**加入代理列表**
5. **重启服务**

#### 方法 2：为终端设置代理环境变量

**macOS / Linux**：

在终端中执行以下命令：

```bash
export https_proxy=http://127.0.0.1:2022
export http_proxy=http://127.0.0.1:2022
export all_proxy=socks5://127.0.0.1:1088
```

**Windows**：

在命令提示符或 PowerShell 中执行：

```cmd
set http_proxy=http://127.0.0.1:2022
set https_proxy=http://127.0.0.1:2022
```

**注意**：
- 这些设置仅在当前终端会话有效
- 关闭终端后需要重新设置
- 端口号请根据实际配置调整

### 如何为不同的浏览器设置不同规则？

**智能代理 APP 规则高级应用，可以让不同浏览器使用不同的代理策略。**

#### 应用场景

在 **TUN 模式**或**智能模式**下，您可以为不同浏览器设置不同的代理规则：

- 🌐 **Chrome**：所有网站都走代理
- 🦊 **Firefox**：所有网站都直连
- 🧭 **Safari**：按网站规则智能分流

#### 配置步骤

**步骤 1：将 Chrome 加入代理 APP 列表**

1. 打开《AI网络加速器》
2. 切换到**规则编辑**页面
3. 切换到 **APP 规则列表**
4. 点击+按钮，在弹出的界面输入或点浏览按钮找到 **Chrome** 浏览器
5. 将其**加入代理列表**
6. **效果**：Chrome 访问的所有网站都会被代理

**步骤 2：将 Firefox 加入直连列表**

1. 在同一个 **APP 规则列表**页面
2. 点击+按钮，在弹出的界面输入或点浏览按钮找到 **Firefox** 浏览器
3. 将其**加入直连列表**
4. **效果**：Firefox 访问的所有网站都会直连，不走代理

**步骤 3：Safari 不加入任何规则**

1. **Safari** 不要添加到任何 APP 规则列表中
2. **效果**：Safari 按照**网站规则**进行智能分流
   - 国外网站自动走代理
   - 网站规则列表中的网站走代理
   - 其他网站直连

**步骤 4：保存并重启服务**

1. 添加后会自动**保存**
2. 切换回控制面板，点击连接按钮**重启服务**
3. 重新刷新各个浏览器访问

#### 实际效果

配置完成后：

| 浏览器 | 代理策略 | 适用场景 |
|--------|----------|----------|
| **Chrome** | 全部代理 | 需要全程使用代理的工作 |
| **Firefox** | 全部直连 | 访问国内网站，不需要代理 |
| **Safari** | 智能分流 | 日常使用，自动判断 |

#### 使用建议

- 🎯 **工作分离**：不同浏览器用于不同用途，提高效率
- 🔒 **隐私保护**：敏感操作使用全代理浏览器
- ⚡ **性能优化**：国内网站使用直连浏览器，速度更快
- 🌍 **灵活切换**：根据需要随时切换浏览器

#### 注意事项

- 必须在 代理模式设置为**TUN 模式** + 规则模式设置为**智能模式**下才能使用 APP 规则
- 修改规则后需要**重启服务**才能生效

### 如何为指定 APP 的不同端口设置不同规则？

**高级技巧：让某个应用的特定端口走代理，其他端口直连。**

#### 应用场景

例如，您希望某个应用：
- **80、443 端口**（HTTP/HTTPS）走代理
- **3266 端口**（其他服务）直连

#### 配置步骤

1. 打开《AI网络加速器》
2. 切换到**规则编辑**页面
3. 切换到 **TUN 规则**
4. 打开**高级规则编辑器**
5. 添加以下规则：

```json
[
  {
    "process_name": ["test.app"],
    "network": "tcp",
    "port": [80, 443],
    "outbound": "socks-out"
  },
  {
    "process_name": ["test.app"],
    "network": "tcp",
    "port": 3266,
    "outbound": "direct"
  }
]
```

#### 规则说明

- **`process_name`**：应用程序名称（如 `test.app`）
- **`network`**：网络协议（`tcp` 或 `udp`）
- **`port`**：端口号（可以是单个端口或端口数组）
- **`outbound`**：
  - `socks-out`：走代理
  - `direct`：直连

#### 实际应用示例

**示例 1：游戏客户端**
```json
[
  {
    "process_name": ["game.exe"],
    "network": "tcp",
    "port": [80, 443],
    "outbound": "socks-out"
  },
  {
    "process_name": ["game.exe"],
    "network": "tcp",
    "port": [3000, 3001, 3002],
    "outbound": "direct"
  }
]
```

**示例 2：开发工具**
```json
[
  {
    "process_name": ["vscode"],
    "network": "tcp",
    "port": 443,
    "outbound": "socks-out"
  },
  {
    "process_name": ["vscode"],
    "network": "tcp",
    "port": 8080,
    "outbound": "direct"
  }
]
```

#### 注意事项

- 必须在 **TUN 模式**下才能使用此功能
- 修改规则后需要**重启服务**
- 应用程序名称需要准确匹配
- 规则按顺序匹配，先匹配的规则优先生效

### 如何下载其他平台版本？

**有两种方式可以下载不同平台的客户端。**

#### 方法 1：在桌面客户端内下载

1. 打开《AI网络加速器》桌面客户端
2. 切换到 **APP 下载**页面
3. 选择您需要的平台版本
4. 按照提示下载安装

**优势**：
- 无需打开浏览器
- 下载链接自动更新
- 方便快捷

#### 方法 2：访问官方网站下载

1. 打开浏览器访问：**[https://resocks.app](https://resocks.app)**
2. 点击**下载**菜单
3. 选择您需要的平台版本
4. 下载并安装

**优势**：
- 无需安装客户端即可下载
- 可以查看详细的系统要求
- 可以下载历史版本

#### 下载建议

- 📥 **首次下载**：建议访问官网下载
- 🔄 **更新版本**：可以在客户端内直接下载
- 📱 **移动设备**：建议在设备上直接访问官网下载
- 💻 **多设备使用**：可以在一台设备上下载，然后传输到其他设备
