# Quick Start

This guide helps you quickly register, log in, and make your first connection after installation.

## Create an Account

ReSocks supports **anonymous usage** — no personal information required:

- Tap "Connect" to start a free trial immediately
- To purchase a subscription, only an email address is needed

## Log In

1. Open the ReSocks app
2. Click the **User icon** in the top-right corner
3. Enter your email and password
4. Click **Login**

## Choose a Node

After logging in, select a server node that fits your needs:

| Node Type | Description | Best For |
|-----------|-------------|----------|
| BGP High-Speed | Multi-country backbone network | Daily use, streaming |
| Dynamic Residential IP | Real IPs in 180+ countries | Bypassing geo-restrictions |
| Static Residential IP | Fixed real IP address | Business use |
| Pure IPv6 | IPv6-only nodes | IPv6 environments |

## Connect

1. Select your desired node (or use the recommended one)
2. Click the **Connect** button
3. Authorize on first connection (see Installation Guide)
4. A green ✅ indicator means you're connected successfully

## Verify Your Connection

After connecting, visit these sites to verify:

- [Google](https://www.google.com)
- [YouTube](https://www.youtube.com)

## Disconnect

Click the **Disconnect** button on the main screen, or simply quit the application.
